# Eisenhower Matrix

## Do: important and urgent (MVP)

- Add internships with their basic details.
- View the list.
- Update statuses, notes, and follow-up dates.
- Save the list and load it again later.
- Show deadlines and follow-ups from soonest to latest.

## Schedule: important, not urgent

- Search by company or role and filter by status.
- Export to CSV.
- Add desktop or email reminders.
- Make a simple graphical interface.

## Delegate: urgent, not important (use built-in tools)

- Use `LocalDate` and `DateTimeFormatter` for dates.
- Use `Files` and `Path` for reading and writing files.
- Use `Comparator` and list sorting to order dates.

## Delete: not important, not urgent

- Apply to jobs or send emails automatically.
- Generate resumes or cover letters with AI.
- Add a social feed, profiles, or messaging.
- Add accounts and cloud syncing.
